# Agentic ITGC Control Testing

Policy document → SAP or uploaded evidence → tested attributes, annotated screenshots
and a Word / PDF report with exceptions.

## Run locally
```
npm install
npm run dev
```
Open the link it prints (http://localhost:5173). Do not double-click index.html.

## Deploy
Every push to `main` builds and publishes to GitHub Pages (.github/workflows/deploy.yml).
Settings → Pages → Source must be **GitHub Actions**.
